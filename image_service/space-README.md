Temporary image and short-video detection for AutoScan AI. No accounts or persistent history.
The frontend runs separately at `/detect`. See `docs/image-workspace.md` in the
source repository for the API, controls, privacy, and deployment limitations.
Video limits and frame-level exports are documented in `docs/video-workspace.md`.

The original contributors and dataset references are preserved at
https://github.com/MS3B09/autoscan-ai#about-the-project-and-authors.

This Space must use explicitly free ZeroGPU hardware. No paid fallback.
